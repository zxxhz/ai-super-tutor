# AI 超级私教（ai-super-tutor）

一个基于六大认知科学原理、把通用 AI 驯化成 5 种「超级私教」形态的 TRAE Skill。

## 如何启用

任意会话中，只要出现触发词即可自动启用（无需手动装载）：

- **通用**：AI 私教 / 超级私教 / 学习辅导 / 教我 / 复习自测 / 请你向我提问 / 考验我
- **模式对应**：见下方速查表

## 5 种模式速查

| 模式 | 触发关键词 | AI 扮演角色 | 适合 | 心法 |
|---|---|---|---|---|
| A 费曼逆向教学 | 讲给你听 / 费曼 | 好奇小白学生 | 概念、英语、抽象机制 | 讲不清楚 = 没真懂 |
| B 苏格拉底考官 | 口试我 / 考我 / 苏格拉底 | 严厉考官（一次一问） | 核心原理、算法边界 | 绝不直接给答案 |
| C 布鲁姆通关 | 通关 / 关卡 / 守门人 | 冷酷守门人（≥80% 放行） | 语言基础、前后依赖课程 | 地基不稳不看下一章 |
| D 魔鬼代言 | 挑刺 / 极端场景 / 能扛住吗 | 挑剔资深架构师 | 软件工程、系统设计 | 极端场景下验韧性 |
| E TDD 对练 | 先用例 / 别给实现 | 测试用例出题官 | 函数、算法实操 | 先看用例再写实现 |

## 使用方法（通用步骤）

1. **提供讲义（事实标尺）**：进入任一模式前，把讲义直接粘贴、或给出文件路径（.md/.txt/.pdf/.docx）、或在当前工作区放置大纲文档，AI 会以其为判分/追问的唯一基准。
2. **选模式**：直接说想用的方式，或由 AI 用选项询问你。
3. **开始学习**：AI 会按对应模式的流程与你交互（鼓励你讲、考你、判分、挑刺、出测试）。
4. **切换模式**：随时说「进入费曼」/「换苏格拉底」/「开始通关」等即可切换，AI 会保留你的学习进度。

## 规则细节（已在 SKILL.md 中内置）

- **语言一致**：AI 全程用你的语言回复。
- **单点聚焦**：一次只处理一个知识点，避免认知负荷超载。
- **共享状态**：讲义、当前关卡、答对题数等跨模式保留，不丢上下文。
- **硬门槛**：布鲁姆模式 80% 未达标绝不放行下一章；苏格拉底模式无论怎么求都绝不直接给答案。
