# AI 超级私教（ai-super-tutor）

一个基于核心认知科学原理、把通用 AI 驯化成 3 种「超级私教」形态的高效学习辅导 Skill。

## 如何启用

任意会话中，只要出现触发词即可自动启用（无需手动装载）：

- **通用**：AI 私教 / 超级私教 / 学习辅导 / 教我 / 复习自测 / 请你向我提问 / 考验我
- **模式对应**：见下方速查表

## 3 种模式速查

| 模式 | 触发关键词 | AI 扮演角色 | 适合 | 心法 |
|---|---|---|---|---|
| **A 费曼逆向教学** | 讲给你听 / 费曼 / 听我解释 | 跨界好奇外行 | 抽象概念、深层原理、直觉建立 | 讲不清楚 = 没真懂 |
| **B 苏格拉底考官** | 口试我 / 考我 / 苏格拉底 | 循循善诱阶梯考官（一次一问） | 逻辑因果、原理推演、思维脚手架 | 知识由你推导出来 |
| **C 布鲁姆通关** | 通关 / 关卡 / 验收这章 | 严谨关卡守门人（5题≥80% 放行） | 章节考核、复习自测、阶段性验收 | 地基不稳绝不放行 |

## 使用方法（通用步骤）

1. **建立事实标尺**：进入任一模式前，把讲义直接粘贴、给出文件路径（`.md` / `.txt` / `.pdf` / `.docx`）、引用工作区大纲文档；若无现成资料，AI 会快速提炼核心考点大纲由你确认，以其为事实基准。
2. **选模式**：直接说想用的方式，或由 AI 引导选择。
3. **开始学习**：AI 会按对应模式的流程深度交互（鼓励你讲、逐步反问启发、5 题量化通关验收）。
4. **切换模式**：随时说「进入费曼」/「换苏格拉底」/「开始通关」即可无缝切换，AI 会保留你的学习进度与认知漏洞记录。
5. **沉淀与复习**：AI 会自动将关键结论与错题沉淀到本地 `learning-notes.md`，并输出艾宾浩斯复习排期。

## 核心设计特性

- **全学科通用**：适用于概念、文理通识、理论推导、外语、自然科学、经济管理与业务逻辑等各类学科。
- **事实标尺与防死锁**：支持粘贴讲义与文件引用；无资料时自动生成共识大纲供用户确认，顺畅启动。
- **学习资产持久化**：自动在工作区维护 `learning-notes.md` 错题本，沉淀知识盲区与回读指引。
- **成长型思维过程反馈**：拒绝廉价谄媚，推行 Process Praise，具体肯定推导逻辑与因果自洽。
- **艾宾浩斯复习排期**：终局输出 +1d / +3d / +7d 动作指引，打通长期记忆。
- **双重编码图解**：支持 Mermaid 流程图与 ASCII 概念结构图。
- **严谨放行**：布鲁姆模式 5 题综合验收，低于 80 分坚决不放行并出具针对性漏洞清单；苏格拉底模式通过 3 级脚手架循循善诱，绝不直接剧透答案。
